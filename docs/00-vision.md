# Visión

## Qué es
Una web para la **previa de hoy (17/10/2026) en casa**: ~100 personas (~50/50 hombres y mujeres), parlantes y luces alquilados. La web es el "animador" de la previa: juegos para romper el hielo, reírse y armar situaciones.

## La máxima (no negociable)
> **No es un producto comercial. Es para esta noche y para estas 100 personas.**
> Todo tiene que sentirse **100% personalizado** para cada invitado.

Consecuencias:
- Se prioriza **velocidad de construcción y diversión** sobre escalabilidad, seguridad fuerte o generalidad.
- Nada de onboarding genérico, términos y condiciones, "crear cuenta", etc.
- Cada pantalla debería poder mostrar el **nombre/apodo/Instagram** de la persona y de otros invitados reales.
- Si hay que elegir entre "genérico y robusto" vs "personal y gracioso" → **personal y gracioso**.

## Alcance
1. Entrada por buscador (nombre / @instagram / apodo) → sesión persistente en el navegador.
2. **Verdad o Reto** (primer juego a construir).
3. Después: juegos picantes, "Acción y Nombre" (otro invitado al azar + 3 acciones), y los que surjan.

## Fuera de alcance
- Autenticación real, passwords, OAuth, verificación de identidad.
- Prevenir que alguien entre como otra persona (es un juego entre amigos, se acepta).
- Uso posterior a la fiesta.

## Uso real
- Se usa desde el **celular**, de noche, con luces y música fuerte, con alcohol de por medio → UI mobile-first, botones grandes, textos cortos, alto contraste, cero fricción.
